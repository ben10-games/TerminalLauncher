# Terminal Launcher

> A minimalist Android terminal launcher with a sarcastic personality.

## 🚀 Features

- 🖥️ Terminal-style Android home screen
- 📱 Launch installed apps with commands
- 🔎 Search installed apps
- 🔋 Battery information
- 🕒 Time and date
- 🧹 Clear terminal
- 🔄 Reset launcher with `forgot`
- 😈 Roast system with Text-to-Speech
- 🤖 Automatic roast system
- 🏠 Android default launcher support
- ⌨️ Terminal-style command input

## 💻 Commands

| Command | Description |
|---|---|
| `help` | Show available commands |
| `clear` | Clear the terminal |
| `time` | Show the current time |
| `date` | Show the current date |
| `battery` | Show battery information |
| `open <app>` | Launch an installed app |
| `search <app>` | Search installed apps |
| `roast` | Get a random roast |
| `forgot` | Return to the startup screen |

## 📱 Installation

1. Go to the Releases page.
2. Download the latest `.apk`.
3. Install it on your Android device.
4. Open Terminal Launcher.
5. Set it as your default Home app if you want to use it as your launcher.
